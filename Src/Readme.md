# SolidJS Niner Accordion

This project demonstrates a SolidJS app featuring an origami-style folding accordion and an animated Fibonacci spiral orb visualization called "Niner Orb".

## Features

- 3D origami folding accordion with smooth animations
- Canvas-based animated Fibonacci spiral orb visualization
- Modern UI with cyan glow and glassmorphic effects
- Accessible, responsive, and visually engaging
